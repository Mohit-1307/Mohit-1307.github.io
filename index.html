01 · about

Curiosity, compiled.

A final-year CS student who treats every project like a production system — not a notebook that only runs once.

The first time I watched a convolutional network learn to read handwritten digits — pixels becoming meaning, layer by layer — I stopped thinking of code as instructions and started thinking of it as perception.

Today I work across the modern AI stack: training deep networks for facial and speech emotion recognition, engineering features for clinical prediction models, and orchestrating multi-agent LLM systems that retrieve, reason and act. I've built RAG pipelines with LangChain and FAISS, and deployed models to AWS EC2 behind FastAPI.

What keeps me here isn't the hype — it's the craft. Good ML is careful data work, honest evaluation and systems thinking. I solve problems on LeetCode to keep my fundamentals sharp, publish my learning openly on GitHub, and treat every project as a chance to build something a real person would actually use.
